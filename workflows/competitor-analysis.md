# Workflow: competitor analysis

Trigger: `/ads:competitors`. Skill: [ads-competitor-research](../skills/ads-competitor-research/SKILL.md).

1. **List competitors** - from the user, the profile, or local search results for the client's core service + city (ask before assuming).
2. **Meta Ad Library** - `ads_library_search` per competitor Page/keyword, country US (or the client's), active ads. Record per ad: start date, format, hook, offer, CTA, landing page.
3. **Google Ads Transparency Center** - browse the advertiser's ads for the client's region (read-only in the browser).
4. **Landing pages** - top 1-2 per competitor: offer, proof, form.
5. **Synthesize** - themes table (table stakes vs gaps), offer comparison, creative style mix, longevity leaders (observed, not proven winners), format trends.
6. **Recommend** 3-5 differentiated tests as briefs in the client's voice; never verbatim copies.
7. Save the summary for the client (user's choice of location; never inside the public repo).
