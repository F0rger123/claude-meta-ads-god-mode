# Ads reporting

Workflow: [workflows/reporting.md](../../workflows/reporting.md). Templates: [templates/monthly-report.md](../../templates/monthly-report.md), [templates/optimization-report.md](../../templates/optimization-report.md).

## Owner summary first (always this order)

```
<CLIENT> - <platforms> - <date range> (vs <previous range>)

SPEND            $2,140  (+6%)
RESULTS          27 leads (+4)   · 9 qualified (CRM)
COST PER RESULT  $79 per lead (-3%) · $238 per qualified lead
REVENUE / ROAS   2 jobs sold, $71k (if known) - otherwise "not tracked yet"

WHAT WON         one or two lines, with the number
WHAT LOST        one or two lines, with the number
WHAT CHANGED     changes we made + outside changes (season, tracking, competitors)
WHAT WE DO NEXT  2-4 concrete actions, each marked needs-approval or not
```

Then platform detail (only metrics that explain the summary): Meta - campaign/ad set table, top ads, frequency/fatigue, learning status; Google - campaigns, search-term waste, impression share, QS issues.

## Rules

- Plain language. Define any metric you must use. No metric dumps.
- Compare like with like: same length windows, same attribution settings; flag the Jan-2026 Meta attribution change if the comparison spans it.
- Say how confident each statement is when data is thin ("only 6 leads - directional").
- Business truth over platform numbers: show CRM-qualified leads when available.
- Never promise future results; give ranges and the assumptions behind them.
- One client per report.
