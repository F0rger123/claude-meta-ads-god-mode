# Learning phase

Source: Meta Business Help Center, "About the learning phase" (facebook.com/business/help/112167992830700). Verify current wording there; Meta adjusts this guidance.

## PLATFORM FACT

- An ad set enters learning when it starts delivering and after a **significant edit**.
- Meta's stated guideline: an ad set generally needs about **50 optimization events within 7 days** of the last significant edit to exit learning. Only the event the ad set optimizes for counts (a Lead-optimized ad set needs Leads, not clicks).
- **Learning limited** = the ad set is unlikely to get enough optimization events. Performance is less stable and usually more expensive.
- During learning, delivery is unstable by design; CPA swings are expected.

## Significant edits (commonly cited; treat as PLATFORM FACT + HEURISTIC)

Changes to targeting, placements, optimization event, bid strategy, adding a new ad/creative, pausing for 7+ days, and large budget or bid changes. Practitioners commonly treat budget changes above roughly 20% at once as risky (HEURISTIC - Meta does not publish a hard threshold).

## Operating rules

1. Do not judge ad sets in learning. Report them as "in learning - no verdict yet" with their event count so far.
2. Batch edits: if an ad set needs several changes, make them together once, not one per day.
3. For learning limited, the fixes in rough order: consolidate ad sets (fewer, bigger), widen audience/use Advantage+ audience, raise budget toward ~50 x target CPA / 7 per day, or optimize for a higher-volume event that still correlates with value (EXPERIMENT; tracking change - approval).
4. Budget math (HEURISTIC): daily budget needed to exit learning ≈ 50 x expected CPA / 7. At $90 CPL that is ~$640/day. Most small local accounts cannot reach it per ad set - which is a reason to consolidate, not a reason to panic. Say this plainly.
5. The guarded-auto default caps a budget increase at 20% per change with a 72 h cooldown for this reason.

## Wording

"This ad set is still learning (19 of ~50 leads in the window). Its numbers will move a lot this week. No changes until it exits or we have 7 full days."
